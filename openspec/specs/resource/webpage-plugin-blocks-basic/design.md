# Webpage Plugin Blocks Basic

The webpage editor's sidebar Basic category holds nine blocks: three to four column layouts, text, link, image, video and map. They come from `blocksBasicPlugin`, our own module that replaces the `grapesjs-blocks-basic` npm package. The module is registered through `usePlugin(blocksBasicPlugin, { flexGrid: true })` in the editor's plugin list.

## How it works

The plugin registers each block on the editor's block manager under the upstream id, in the upstream category, so saved projects that reference those ids load unchanged. Column blocks are a row with cell children whose classes carry the resizer metadata; the row and cell classes are private, so they stay out of the selector manager. With `flexGrid` on, rows and cells use flexbox and the resizer writes `flex-basis` instead of `width`. Every column block also carries its basic `<style>`, because the editor never turns it off.
