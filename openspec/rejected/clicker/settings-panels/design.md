# Settings panels not taken

Settings for the clicker that the game does without, one section each. Each is refused as a settings surface out of proportion to what the setting changes.

## Number notation

A display setting switching between the long word notation the game uses today ("1.5 million", via `formatNumberLong`) and a compact `k/M/B` notation.

**Why not:** One game, one number style. A settings surface for a pure formatting preference is UI overhead with no gameplay value, and the long names are part of the game's charm. The compact notation the Sheet's number format uses is a spreadsheet's, and the game's numbers are read as words on purpose.

## Sound volume and mute

A volume slider and a mute toggle for the buy sound, the clicker's one effect.

**Why not:** The game plays a single short effect sound; the browser tab-mute covers anyone bothered by them. A settings panel for this is disproportionate. Revisit only if the game ever gains music or ambient audio.
