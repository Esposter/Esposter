# Fit width button

A control on the PDF viewer's primary bar that fits the pages to the width of the view.

## Why not

The zoom readout is the reset, and it returns the scale to the one a document opens in, which fits the document to the container. A reader who wants the page back in view already has that route in the readout, so a Fit width control beside it would hold a second route to a fit and spend the bar's width on it.
