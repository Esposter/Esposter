# Page field Go button

A button beside the page field on the PDF viewer's primary bar that goes to the page typed there.

## Why not

The page field commits on Enter, so a Go button beside it is a second control for one job. The field is the one place a page number is typed, and Enter is the key a reader already uses to commit a value, so the button would only repeat that key and add a target to the bar. The bar holds the controls every session uses, and a repeat of one of them does not earn a place on it.
