# User Setting Slider

A slider for a user setting that edits a clone of the stored value and writes the clone when the reader lets go of the thumb. Four of the user settings' sliders draw it.

## Why not

Three of the four are a clone of one stored value and one write on the slider's end, a line or two each, and the copies have not drifted. The input sensitivity slider also draws a live microphone level, so it is not the same shape. A shared piece would take a line from each site without taking anything else, which is below the bar a shape earns a shared piece at: a consumer beyond these sites, or a mistake the shape would remove. Reopened by a slider outside these needing the same clone and write, or by one of the three writing on every move or dropping the value its clone holds.
