# Saved Views on the Resource List

Named view sets in the style of a cloud portal's "Manage view": a filter, column and sort combination saved under a name and recalled from a views dropdown.

## Why not

The URL already holds the filters, the sort and the column widths, which makes any view reproducible by bookmarking the URL ([list filters and views](../../../specs/resource/list-filters-and-views/design.md)). Named server-side views would add a table and procedures for convenience only. Reopened when filter combinations are rebuilt by hand repeatedly, or views must be shared between devices or users.
