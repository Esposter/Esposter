# VuetifyComponent resource type

Porting the table editor's `VuetifyComponent` item type (a table of Vuetify component demos) as a resource type.

## Why not

It was a component demo with no persistent data value — no user artifact worth naming, listing, or sharing. Porting it would mean inventing a resource type nobody needs; the demo can live in a storybook-style page if ever wanted.
