# Portal chrome extras

Breadcrumb segment dropdown pickers, a feedback smiley, guided tours, Home docs, tutorial and "Useful links" cards, localization of the explorer, and tabbed Overviews ("Get started" tabs), each with no workflow behind it here.

## Why not

Each is cosmetic fidelity to a need the app does not have — no docs product to link, no feedback pipeline, one language, Overviews short enough that tabs would hide content. Copying them adds surface area without adding a single user action that matters.
