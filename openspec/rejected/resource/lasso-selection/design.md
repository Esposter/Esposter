# Lasso selection

Selecting the elements inside a freeform loop drawn around them, as an alternative to the marquee.

## Why not

The marquee already selects every element a drawn box fully covers, and the [whiteboard spec](../../../specs/resource/whiteboard/spec.md) names that set. A lasso selects by a drawn outline instead, so it differs only where a box cannot follow the arrangement of the elements. A reader can already add to a selection with Shift-click, so the second gesture answers little that the marquee and Shift-click do not.
