# One Question Per Page

SurveyJS can show a survey as a card view with one question on each screen. This record covers that layout.

## Why not

Pages are the runner's only grouping, and the multi-page runner already moves a respondent through them with Previous and Next ([survey runner design](../../../specs/resource/survey-runner/design.md)). A survey with one page per question gives the same run through the runner it has. A card view would be a second runner mode to keep in step with the first.
