# Console Computer Use

The Code tab's computer use: Claude can "open your apps, control your screen, and work directly on your machine", a research preview that "runs on your actual desktop with access to whatever you approve" ([Claude Code desktop](https://code.claude.com/docs/en/desktop)).

**Why not:** The console is a page over the host's sessions, and the host's reach is the repository and the tools a session already runs. Controlling the desktop is a capability of the desktop app's own process, with the operating system's accessibility and screen-recording grants behind it; a browser page cannot hold those, and a host that took them would hand every holder of its token the whole machine rather than one repository. A session that needs the desktop is run in the desktop app.
