# Agent Console

**Why not:** The console was judged by one test: a day's work done in it without going back to a terminal. That test never held, and what it would have taken to hold was every surface Claude Code already has, drawn a second time. Its own parity list was the list of what the terminal shows, and each row has a first-party home: the [desktop app](https://code.claude.com/docs/en/desktop) runs the same engine with a sidebar of parallel sessions and optional worktrees, a diff view with comments on a line, a review command, and sessions that can message one another, and agent IDEs such as [Orca](https://www.onorca.dev/) run several agents in worktrees with remote use over SSH. A surface that is level with those only after continual work, and gives a person nothing they could not already do, is a copy.

What Esposter owns is its content: resources, follow-ups and the activity around them, reached through an MCP door under the person's own key ([agent content tools](../../../specs/architecture/agent-content-tools/design.md), [agent access](../../../specs/architecture/agent-access/design.md)). That door is the same from a terminal, the desktop app, an agent IDE or a harness pointed at another model, so the content needs no surface of ours to reach an agent. Its one consumer in the app, Ask Claude, needed a way to carry a line to a session, and a prompt the person pastes carries it to any agent.

The premise was also weaker than it read. The console drove each session through the Agent SDK, which draws from the subscription's usage limits as the [Claude interface](../../../specs/infra/claude-interface/README.md) states, on terms the platform has announced a change to and paused, with a separate credit now for API-key use ([the plan page](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan)). It is the same fact that rejected the [SDK-driven companion](../sdk-driven-companion/design.md). A surface that only watches Claude Code's own session depends on none of it, which is what the [agent sidecar](../../../deferred/infra/agent-sidecar/design.md) would be.

The cost of keeping it was real and growing: a host package with a native terminal dependency and the Agent SDK, a Windows executable carrying Node and the Claude Code binary, a large page tree unmounted from the app while it waited for a rebuild, and a parity treadmill with a tool that moves on its own.

**What went with it:** every idea that was a part of the surface. The terminal-mirror driver, themes, the wish banner, element ambience, spatial chat, effort level, session titles, Anthropic-hosted sessions and extensions were its follow-on changes. Cross-session messages, the session archive, split sessions, task suggestions, worktree sessions, WSL sessions and signed host installers were deferred for it. The browser pane, computer use, the customize panel, the environment editor, the pane layout, the pull request bar, scheduled tasks, session shortcuts and view modes were rejected for it.

**What stayed:** the persona, the spoken replies and the mods, which are hooks and an output style on the terminal's own session; Esposter's content behind the MCP door; and Ask Claude, which composes the prompt and offers it for copying.
