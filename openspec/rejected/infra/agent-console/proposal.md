# Agent Console

A page of the app that worked Claude Code sessions in place of the terminal: the conversation, tool calls, diffs, permission prompts, subagents, resume, fork and rewind, served by a host program on the person's machine over a paired WebSocket. It was dressed as the Genshin game, and it carried a terminal tab, a read-only file view, a side pane of the app's own pages, comments on a diff, a side chat and a Windows executable that held the host.
