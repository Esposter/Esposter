# CDN in front of Blob storage

The game's data is published as immutable, content-addressed objects in the app's public R2 bucket, `public-genshin-assets`, and the browser fetches each one once and then caches it ([hosted game data](../../../specs/genshin/hosted-game-data/design.md)). A CDN in front of that bucket would serve those objects from its own edge, so most reads would never reach storage.

**Why not:** immutable caching already answers a repeat visit with no request, and a first visit reads a few hundred kilobytes, so a CDN buys little on the browser side. The price comparison was made on the storage and CDN the Cloudflare program retires, so its figures no longer hold and are not restated here. A CDN would also be a second service with its own domain, cache rules and failure mode, the trade the [CDN in front of Railway](../cdn-in-front-of-railway/design.md) page already refuses. Adding one later would change only the base URL the browser reads, so the decision can be revisited then without touching the code.
