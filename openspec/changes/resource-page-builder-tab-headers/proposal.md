# Page builder and email editor tab headers

## Why

The tab headers of the page builder's node settings (Content, Style and Theme) and the email editor's Design and Preview toggle do not match the app's own tab headers. Their active state is hard to see and their spacing differs from the rest of the app. The owner also named a Layout tab, which I have not located in the code yet.

## What changes

- The page builder's node settings tabs and the email editor's Design and Preview toggle take the app's tab header style, with a clear active state and the same spacing.
- The Layout tab the owner named is found in the browser before anything is restyled for it.

## Out of scope

The email canvas, Preview's transport and the canvas frame, which have their own changes.
