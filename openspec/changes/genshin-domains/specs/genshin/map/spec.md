## ADDED Requirements

### Requirement: Only statues, waypoints and domain entrances are jump landmarks

Only Statues of The Seven, Teleport Waypoints and Domain Entrances SHALL be jump landmarks, and a tree SHALL never be a jump.

#### Scenario: Tree in a region

- **WHEN** a tree is in a region's data
- **THEN** it is not offered as a jump
