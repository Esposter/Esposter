# Resource roadmap

Every product is already a resource behind one [explorer](../../specs/resource/explorer/design.md), whose shell has closed its gap with the Azure portal; what is open now is the depth of each type against the product that already solved its domain — Microsoft To Do for the TodoList, Google Forms for survey responses, Notion for the Note, Power BI for the Dashboard, Mailchimp for the Email, Webflow for the Webpage, Qualtrics' distributions for the Program and the Azure portal's template deployment for the Blueprint. Items link their full specs under [proposals](../) — directly or via their section heading; the specs are the plan, this page is only the priority order. Check [deferred](../../deferred/resource/) + [rejected](../../rejected/resource/) before adding items, and the [sheet editor](../../specs/resource/sheet/README.md)'s own pair for anything inside the Data blade — the grid keeps its backlog with the editor. New Azure services are the only real cost anywhere below; everything else is frontend + procedures + at most a Postgres migration.

## Next

- [ ] [Survey purge](../archive/2026-11-04-resource-survey-form-engine-removal/design.md) — publish `PurgeSurveyResources` to the application topic once in each environment, then verify zero survey rows, response rows and invite references and an empty rerun. This needs the owner, and it waits until the Azure Functions host runs the repo's Node major (the node-major reference under `.agents/skills/dependency-updates/references/node-major.md`)

- [ ] [Survey runner and Creator accessibility](../../specs/resource/survey-fields/design.md) — owed: the owner's one screen-reader listening to the runner's errors and the Creator's list editors; reported and open: a required multiple-text item left empty does not stop a submit or show an error (the engine's answer check, not the field), and a text field's focus is a 10% accent tint at about 1.1:1 against its surround with its ring left transparent, which is a design call on the focus indicator

- [ ] [Browser suite for the resource editors](../../specs/resource/whiteboard/design.md) — a package browser suite, since layout claims wait for one (the `testing` skill): the whiteboard canvas and PNG export, the Note image width cap, and the page builder's colour probe on a non-sRGB colour, none of which happy-dom can show; and three dashboard cases, by their names in [the dashboard-grid spec](../../specs/resource/dashboard-grid/spec.md): 'Handles are hidden while a visual is not pointed at or focused' (the handles of an idle visual), 'A visual shows an outline when pointed at or focused' (the accent outline), and 'A published visual shows no outline' (none on the published page)

## Later

- [ ] [Flowchart removal's client delta](../archive/2026-11-02-resource-flowchart-retirement/proposal.md#bundle-measurement) — measure the client bytes the removal released against the last release before it. The archived change's task 3.5 is ticked, but its proposal records only the built size of the five Vue Flow packages, a ceiling, so the exact delta is not on record; this item measures it, or the owner accepts the ceiling as the figure

- [ ] [Page builder](../resource-page-builder-program/design.md) — the Webpage and Email editors rebuilt on a typed node tree and MJML on the server, with GrapesJS and its plugin belt removed in one cutover; it replaces the plugin-belt pruning, which stops now — the cutover, email and style-panel changes are archived, while the canvas and performance-and-proof changes are archived with tasks still open, and the program's own tasks 4.1, 5.1 and 5.2 stay open until they close: the browser proof of both editors, the editor script sizes measured on the cutover's production build, and the purge and the Blueprint backfill run once in each environment

- [ ] [Simplify the math expression language](../../specs/math-expression-compiler/language/design.md) — the function table shrinks to what a spreadsheet or school mathematics uses, so the special functions and number-theory exotica (bernoulli, zeta, catalan, stirlingS2, lgamma, erfinv and bellNumbers) go; `%` becomes postfix percent only, with modulo written `mod()`; and implicit multiplication binds like an explicit `*` (the mathjs exception `1/2 x` is removed). Each change needs a backfill of the stored column transformations first (the `backfills` skill), so none of it is done silently
