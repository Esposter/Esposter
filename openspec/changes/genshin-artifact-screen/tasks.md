# Tasks

Each built task names the test it was written first in, and each test is a scenario of the spec delta.

## 1. Tables

- [x] 1.1 The world reads the artifact rarity and EXP tables into its stat tables. Covered by the existing character, kit
      and save suites, which parse the stat tables; the schemas enforce each table's shape, so no test of its own.

## 2. Set bonuses

- [x] 2.1 `getActiveArtifactSetBonuses` reaches each set's bonus at its piece count, and the attribute sum reads it.
      Tests: "a set's two-piece bonus is active from two pieces", "a set's four-piece bonus is active from four pieces", "a
      single piece of a set activates none of its bonuses", "a set the table does not hold is refused".

## 3. Equip and unequip

- [x] 3.1 `equipCharacterArtifact` puts a piece in its slot and returns the piece it replaces. Tests: "equipping into an
      empty slot displaces nothing", "equipping into a worn slot returns the piece it replaces".
- [x] 3.2 `unequipCharacterArtifact` takes off a slot's piece and refuses an empty slot. Tests: "unequipping returns the
      worn artifact and leaves its slot empty", "unequipping an empty slot is refused".

## 4. Enhancing a worn artifact

- [x] 4.1 `enhanceCharacterArtifact` charges the Mora and enhances the worn piece, and refuses without it. Tests: "a worn
      artifact takes the materials' EXP and its fodder's, and the Mora they cost is charged", "an enhancement the wallet cannot
      pay for is refused", "an enhancement of an empty slot is refused".

## 5. The Artifacts panel

- [x] 5.1 The Artifacts tab's panel: the five slots, the picked slot's name, the set bonus block and the Enhance and Equip
      or Unequip actions. Its case is the visual suite's `CharacterMenuArtifacts` fixture and its `worn` variant. Its words
      are the artifact members of `GameTextKey`, which the text map's next write carries, and the character screen's
      Artifacts tab passes it those words, the slot names and the set block's state.

- [x] 5.2 The set bonus lines. Each bonus the worn set reaches is a line in the game's set line, `EQUIP_RELIC_SET_NUM`,
      its effect's words read from the names record by the text hash its affix row holds (`descriptionTextHash`, read by
      `getArtifactSetDatas`). Tests: "each bonus is a line with its piece count and its effect's words" and the two
      after it in `getArtifactSetBonusLines.test.ts`. The stats data and the names record are regenerated by
      `genshin:assets stats` and `genshin:text names`, which the main session runs.

- [x] 5.3 The picked artifact's main and sub stats under the details pill, provisional. The stats take the Details list's
      row pitch from the registered frame and their place is not measured, since no reference frame shows a picked piece.
      The sub stats are read from the piece's minor affixes; the main stat's name is read from its main affix, and its
      value waits on the main affix pools (6.3). Tests: `getArtifactDetailStats.test.ts`, and the visual suite's `worn`
      variant, which the main session runs.

- [ ] 5.4 The panel's parity reference and its approval, once the reference frame is fetched and its compare is clean.
      Waits on a browser run.
