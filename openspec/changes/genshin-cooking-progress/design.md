## Decisions

- **The save holds the cooking progress as one required `cooking` slice.** It carries `learnedRecipeIds`, `proficiencies` (each dish's proficiency by its id) and `processingJobs` (each processing's queue by its id, with the count and the instant its first unit started). The slice has no default, as crafting has none: a stored save without it is backfilled once, so no read path carries a fallback. The caps are the cook table's row count (`MAX_COOKING_RECIPE_COUNT`), since dishes and processings share one table.
- **A merge keeps the higher proficiency, the union of learned dishes and the later-started queue.** A proficiency only grows, so the higher of the two copies is kept per dish. A learned dish is never unlearned, so the learned list is a union. A queue is one copy's whole, so the copy started later wins per processing, and a processing only one copy holds is kept.
- **Using an instruction item teaches its dish, routed by the item's id.** An instruction is recognised by a recipe's `unlockItemIds`, as Fragile Resin is routed by its id, because no item category names instructions. An instruction the dish has already taught is not usable.
- **The stove lists the dishes the cook knows.** A dish is listed when `checkIsCookingRecipeOpen` holds for it, so the list is the known-from-the-start dishes and the learned ones, replacing the provisional first-known pick.
- **Auto Cook is offered once a dish's proficiency is full.** The screen's enabled state is `checkCanAutoCook`, which also withholds it from the Raiden Shogun, as `autoCookRecipe` refuses her. The batch is made by `autoCookRecipe`, and the screen closes as Stop does, whether or not a batch was made. The button's text is the game's `UI_COOKING_QTE_AUTO_MAKE_BUTTON`, a new `GameTextKey` member.
- **One name in the items table serves every source of an instruction.** The items builder names each cook recipe's unlock items, so the shops' instruction goods (141 in the dump) and the quest rewards that give one deliver an item the bag can hold. The stove opens on the first dish the cook knows, provisionally, and the player chooses from the rest.
- **The dev backfill writes the empty slice.** A stored save without `cooking` is given `cooking: { learnedRecipeIds: [], proficiencies: {}, processingJobs: {} }`, the state a player who never cooked holds, since the progress was never saved before this change.
