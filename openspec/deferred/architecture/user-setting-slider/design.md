# User setting slider

A slider for a user setting that edits a clone of the stored value and writes the clone when the reader lets go of the thumb. Four of the user settings' sliders draw it.

## Why deferred

Three of the four are a clone of one stored value and one write on the slider's end, a line or two each. The input sensitivity slider also draws a live microphone level, so it is not the same shape. The three copies have not drifted, and a shared piece would take a line from each site without taking anything else. That is below the bar a shape earns a shared piece at: a consumer beyond these sites, or a mistake the shape would remove.

## Revisit when

A slider outside these needs the same clone and write on release, or one of the three is found writing on every move, or dropping the value its clone holds. Either gives the shape a consumer or a defect that one owner would remove.
