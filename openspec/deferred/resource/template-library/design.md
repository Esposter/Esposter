# Template Library

A library of ready-made page content an author inserts into a webpage, from the palette and from the templates tab. It covers the webpage row "Template library" under the palette and the webpage row "Template library" under Templates. The reference product's docs read name no template library.

## Why deferred

A blueprint's webpage entry deploys as an empty document ([blueprint resource](../../../specs/resource/blueprint-resource/spec.md)), so no curated page content reaches an author today. A template library needs a source for that content, and no design says where it comes from: a set the app ships, an owner's own pages or a blueprint an owner curates. Without that source the library has nothing to hold.

**Revisit when:** a design says where curated page content comes from and what inserting one does to a page.
