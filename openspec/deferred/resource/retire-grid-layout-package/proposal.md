# Retire the grid layout package

## Why

Deferred: the dashboard's tiles sit on a grid package of their own, and an editor layout engine now arranges every editor's regions. If the dashboard needs no free placement of tiles, the grid package has no job the engine or a plain CSS grid could not do, and it could be removed and unpublished.

Nothing yet: this idea is deferred. Its argument and revisit trigger are in `design.md`. Reviving it moves this folder into `openspec/changes/`.
