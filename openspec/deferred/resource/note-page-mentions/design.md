# Note page mentions

Typing `@` in a note to link to another resource, drawn as an inline link to it, as Notion's page mention does.

## Why deferred

A mention is a reference from one resource to another, and the platform tracks a reference only where a resource binds another's data, as a dashboard binds a sheet. A text mention is a link the owner can already paste, and a stored mention would need the delete warning and the share flow to know about it, or it would dangle.

## Revisit when

The explorer shows what links to a resource, or the delete warning reads references from content other than bindings, so a mention would be a reference the platform already knows how to keep.
