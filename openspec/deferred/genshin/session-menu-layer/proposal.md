# Session menu layer

The world session's menu layer becomes a child component of the session root. Today its markup is one `MenuScreen` with a page body in each of its slots, several hundred lines of template inside the root's own template, and it reads many values the root's composables return and reports many events back to them. The root already mounts the HUD, the workshop, the screens, the statue and the challenge layers as children. The menu layer is the one block left inline, and it is the largest.

The earlier build took the cut as one child that mounts the menu screen with its pages as slot content, props typed by the models the pages show, `defineModel` for the values the pages edit, and events up to the handlers the root already binds. [The design](./design.md) records what that cost and weighs it against two cheaper shapes, so which shape is built is still to be decided; the exact code of the earlier build is [recorded](./recorded-build.md).

**Why deferred:** the checker cannot hold the cut. The Vize content mapper builds a component's event map by recursing over the overloads of its emit function, and the recursion loses a component's earliest events once it declares more than sixteen, models included, without an error. A child with the menu layer's events fails the package typecheck with one `Property '<name>' does not exist on type '$StaticEventMap'` for each declared event, reported in generated code that has no line in the source. Splitting, merging or renaming the events to stay under sixteen would bend the code to the tool, so the layer stays inline and the cut waits for the tool. The defect is drafted as an upstream report in [the vize typecheck change](../../../changes/architecture-vize-vue-typecheck/reports/event-map-overload-cap.md), and the layer's block in the root carries the matching `@TODO`.

**Revisit when:** the Vize release the workspace installs builds a component's event map from the keyed events it declares and not from its overloads. Lifting the recursion limit alone is not enough, since the compiler then stops the same recursion with an error before the largest layer. The test is a component declaring models and more than sixteen events that typechecks with every event present, which the report's reproduction is.

**Cheaper interim:** none is needed. The layer works inline, and the root's other layers are already children.
