- [Keyword notification rules](/docs/esbabbler/rejected/keyword-notification-rules) — mentions already cover it
- [Read receipts / unread badges](/docs/esbabbler/rejected/read-receipts-unread-badges) — doesn't fit the casual UX; mention-only counts allowed
