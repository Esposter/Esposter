# Room Discovery

A public directory of opt-in discoverable rooms, joinable without an invite.

**Why deferred**

- Rooms are private-by-invite today; discoverability changes the trust model (spam, raids, moderation load) and needs [raid mode](/docs/esbabbler/deferred/raid-mode)-class tooling first.
- Overlaps the platform-level [public discover feed](/docs/platform/deferred/public-discover-feed) — if a public surface ships, it should be one design across resources and rooms, not two.

**Revisit when:** the platform builds its public discover surface, or user growth makes invite-only onboarding the bottleneck.
