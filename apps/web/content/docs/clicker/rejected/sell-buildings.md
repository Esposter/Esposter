# Sell Buildings

Selling owned buildings back for a partial refund, Cookie Clicker style.

**Why not:** In a game with no building caps or run constraints, selling is never the right move — it only exists in Cookie Clicker to service mechanics we don't have (ascension math, seasonal switches). It adds refund-rate balance questions and stats ambiguity (`producedValue` of sold units) for a button nobody should press. Reconsider only as part of a prestige design if that ever lands.
