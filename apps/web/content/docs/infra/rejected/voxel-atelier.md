# Voxel atelier

The proposal gave a session a room: a voxel floor and walls in the character's region's palette, the character's voxel figure at its centre, and each event on the session's stream changing it a little (a block for an edit, a lantern for a commit, a wilting plant for a failed check), so a session's work left a picture behind.

**Why not:** It was a voxel room with a voxel figure, and the console's world is now the [Genshin](/docs/proposals/genshin) recreation. The character belongs in that world, drawn by the play features the program writes once the world is walkable, not in a second scene beside it. A session's record is already the console's timeline and changes tabs.
