# Codebase city

The proposal laid the repository out as a squarified treemap: top-level folders as districts, files as buildings whose height was their line count and whose glow was their recent churn. The person walked the voxel player through it, a second figure walked to whatever file the session touched, and standing at a building scoped a prompt to that file.

**Why not:** It rested on the voxel world's player and its blocks, both gone. The console's world is the [Genshin](/docs/proposals/genshin) recreation, whose ground is the game's own continent, so a city drawn from the repository has no place in it. The work it wanted to show is what the console's changes tab and timeline already list.
