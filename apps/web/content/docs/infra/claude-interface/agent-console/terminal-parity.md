# Terminal parity

The [agent console](/docs/infra/claude-interface/agent-console) replaces the terminal only if nothing is lost in the move, so every row here is something the terminal shows or does, set against the part of the page that carries it. A row marked partial says what is missing. The shortfalls are the work before the console can take a whole day's work without the terminal being opened.

## What the terminal shows

| Terminal surface                   | Where the console carries it                                                                                                                                                                                                                     | Status                                                                                                                                            |
| :--------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------ |
| The conversation                   | the conversation panel, answers rendered as sanitized markdown with the main agent's tool calls in place between them, a search over the session, a copy button on every answer and every code block in it                                       | done                                                                                                                                              |
| Thinking                           | a row per thinking block, open as it arrives and folded on a click, summarized rather than omitted                                                                                                                                               | done                                                                                                                                              |
| Streaming as it is written         | each block of a reply as it completes                                                                                                                                                                                                            | partial: the host maps the SDK's whole messages, not its partial ones, so a reply appears a block at a time rather than word by word              |
| The working spinner and its tips   | a working line at the end of the conversation: a spinner, a verb picked for the turn, the seconds since the prompt, Escape to interrupt, and a tip                                                                                               | partial: the tips are the console's own, since the SDK does not send Claude Code's, and the line counts no tokens, since no partial usage arrives |
| Tool calls and their results       | each call in the conversation where it was made, folded to its name, what it was called on, its duration and its mark, with the first lines of its result under it; the character at the station of the call it waits on; and the timeline panel | done                                                                                                                                              |
| File edits                         | a side-by-side diff per edit, the pages stacked on the workbench, and the changes panel grouping every edit by file                                                                                                                              | partial: a file's edits are listed in order, not merged into one diff against where it started                                                    |
| Subagents                          | a figure per running subagent, and a timeline lane per subagent beside the main one, titled by its task and marked with its status                                                                                                               | done                                                                                                                                              |
| Permission prompts                 | the character waiting at the gate with its lantern lit, and a panel with the tool and its whole input, an edit shown as its diff; allow, always allow, or deny with a message                                                                    | done                                                                                                                                              |
| Model, context used, cost          | the model in the composer; the context vessel and the heads-up display, which warn at nine tenths of the compaction threshold; the coins and the cost so far                                                                                     | done                                                                                                                                              |
| Plan usage                         | the usage panel with the usage window's share, coloured once the SDK warns                                                                                                                                                                       | done                                                                                                                                              |
| Todo list                          | a checklist at the top of the timeline panel                                                                                                                                                                                                     | partial: the Claude Code build the SDK ships gives SDK sessions no todo tool, so it stays empty                                                   |
| Hook output                        | a folded row where the hook fired                                                                                                                                                                                                                | done                                                                                                                                              |
| Session start output — the persona | the SessionStart hook's row                                                                                                                                                                                                                      | partial: shown as a row; a theme reading it is the [Genshin theme](/docs/proposals/infra/agent-console/themes)                                    |

## What the terminal does

| Terminal action                 | Where the console carries it                                                                                             | Status                                                                                      |
| :------------------------------ | :----------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------ |
| Send a prompt                   | the composer; Enter sends and Shift+Enter breaks the line                                                                | done                                                                                        |
| Attach a file                   | paste or drop into the composer                                                                                          | partial: images only; other files are named in the prompt, as the terminal does with a path |
| Interrupt a turn                | the stop button and the Escape key                                                                                       | done                                                                                        |
| Slash commands                  | a palette listing the session's own commands, the person's skills and plugins included                                   | done                                                                                        |
| Plan mode, accept edits, bypass | the mode select in the composer                                                                                          | done                                                                                        |
| Switch model                    | the model select in the composer                                                                                         | done                                                                                        |
| Resume and continue             | the sessions, from the board or the heads-up display: a closed session resumes on a click, its transcript replayed first | done                                                                                        |
| Fork                            | the sessions, or from any message                                                                                        | done                                                                                        |
| Rewind                          | from any message                                                                                                         | partial: the conversation rewinds; the files the later turns edited do not                  |

## Notes

- Every row marked done reads the fold of the recorded session, which the fold and figure tests replay; what the panels and the world draw from it is checked by eye. A live session driven end to end from the page, a prompt through a permission request to a turn's end, is the check this page has not had: the host was run live for pairing, opening, the palette's commands and models, the context gauge and closing, and nothing further.
- The page does what the terminal cannot in the rows above: parallel sessions each with their state one click apart, a notification when a hidden session needs attention, a search over the session, and a diff for every edit, including the one a permission request is asking about.
