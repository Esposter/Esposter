# Portal chrome extras

The remaining Azure-portal chrome with no workflow behind it here: breadcrumb segment dropdown pickers, the feedback smiley, guided tours, Home docs/tutorial/"Useful links" cards, localization of the explorer, and tabbed Overviews ("Get started" tabs).

## Why not

Each is cosmetic fidelity to a portal need we don't have — no docs product to link, no feedback pipeline, one language, Overviews short enough that tabs would hide content. Copying them adds surface area without adding a single user action that matters.
