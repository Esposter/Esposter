# Dashboard Pages

A Power BI report holds any number of pages, each its own canvas, switched by tabs under it, and can hide a page from readers.

## Why not

A page is a second dashboard with a shared name. The explorer already holds as many dashboards as an owner wants, each published, tagged, favourited and restored on its own, and a page inside one would be a second hierarchy beside the explorer's — the reason [note workspace nesting](/docs/resource/rejected/note-workspace-nesting) was rejected too. A hidden page is a draft, which an unpublished dashboard already is.
