# Autosave

Saving the run automatically on a timer or on every meaningful event, like the clicker does.

**Why not:** Manual saving is a deliberate genre mechanic here — checkpointing is a decision, respawn-after-wipe has stakes, and the Smith NPC exists to teach it. It also keeps save-count achievements meaningful. Distinct games, distinct persistence cadences; the shared `useSave` layer supports both without either compromising.
