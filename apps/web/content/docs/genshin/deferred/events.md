# Events

The game runs limited-time events beside its permanent world: a festival's quests, a minigame for a few weeks, a combat challenge with its own rules, opened from the Events screen on F5 and closed when its window ends, often for good.

**Why deferred:** an event's window is opened and closed by HoYoverse's servers. The community's dump holds each event's configuration, but no event's dates, so the world has no calendar to open one by. Each event is also content of its own, a minigame with rules found in no other, among hundreds of activity tables, rather than a system later pages build on; recreating them is one bespoke build per event, chosen one at a time.

**Revisit when:** an event is chosen to keep as permanent content of the world, which then gets its own proposal and opens without a window, or the game's own data carries events' dates.
