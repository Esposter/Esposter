# Rejected

Ideas we decided against. Check here before proposing — never re-argue a decided idea.

- [Hosting the official character packs](/docs/genshin/rejected/hosting-official-character-packs) — HoYoverse's MMD packs published to the app's Blob Storage for every browser to fetch; every pack's terms forbid redistributing it.
- [Reference board](/docs/genshin/rejected/reference-board) — a region drawn by hand over the official map and judged as an overlay by eye; the game's own data holds the layout exactly, and each pass has its own measure.
- [Static data in public assets](/docs/genshin/rejected/static-data-in-public-assets) — the game's generated tables served from the app's own public assets; the data would ship in every build and deploy and leave through Railway at its per-GB rate.
