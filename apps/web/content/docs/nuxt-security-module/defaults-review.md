# nuxt-security defaults review

The module's defaults are the first thing a new app inherits, so the absorbed package starts from a reviewed set rather than from upstream's. This page reviews each header and option the module sets by default against published guidance. It is the input to the next phase: the package's defaults are written from the verdicts below, and each verdict that changes a value gets a test pinning the new value.

The default set is read from the installed `nuxt-security@2.6.0` in `defaultConfig.mjs`. Our app does not set `strict`, so the non-strict defaults apply, and the strict set is noted where it differs. Recommended values are quoted from the sources linked in the last section. Where a source could not be read, the verdict is marked undecided rather than filled from memory.

## Headers

| Header                                 | Module default                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Recommended                                                                                                                                                                                                                                                                                                          | Verdict                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| :------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Content-Security-Policy`              | `base-uri 'none'`, `font-src 'self' https: data:`, `form-action 'self'`, `frame-ancestors 'self'`, `img-src 'self' data:`, `object-src 'none'`, `script-src-attr 'none'`, `style-src 'self' https: 'unsafe-inline'`, `script-src 'self' https: 'unsafe-inline' 'strict-dynamic' 'nonce-…'`, `upgrade-insecure-requests`. Strict: `default-src 'none'`; `connect-src`, `font-src`, `frame-src`, `img-src`, `manifest-src`, `media-src` and `worker-src` each `'self'` alone; `style-src 'self' 'nonce-…'`; `script-src 'self' 'strict-dynamic' 'nonce-…'`; and prerendered styles hashed (`ssg.hashStyles`) | OWASP: `default-src 'self'; form-action 'self'; base-uri 'self'; object-src 'none'; frame-ancestors 'none'`. Our `base-uri 'none'` is stricter than OWASP's `'self'` and stays. CSP3 §3.3 says `frame-ancestors` is ignored in a `<meta>` element, so it only protects when sent as a header, which the module does. | **Change**: the default has no `default-src`, so every fetch type without its own directive is unrestricted. Add `default-src 'self'`. `frame-ancestors 'self'` stays, not OWASP's `'none'`, because our agent console frames same-origin pages.                                                                                                                                                                                                                                                                                                                                  |
| `Strict-Transport-Security`            | `max-age=15552000; includeSubDomains` (180 days). Strict: `max-age=31536000; includeSubDomains; preload`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | OWASP: `max-age=63072000; includeSubDomains`. RFC 6797 §6.1.1 defines `max-age` in seconds from receipt, and §8.1 requires a UA to ignore the header over plain HTTP.                                                                                                                                                | **Change** `max-age` to `63072000` (two years). `preload` stays out: the preload list is a separate commitment to take on its own.                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `X-Frame-Options`                      | `SAMEORIGIN`. Strict: `DENY`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | OWASP: `deny`. MDN: `DENY` blocks framing from any origin, and CSP `frame-ancestors` is the more complete control.                                                                                                                                                                                                   | **Keep** `SAMEORIGIN`. `DENY` would block our agent console, whose side pane frames same-origin pages (`apps/web/app/components/AgentConsole/Pane/SidePane.vue`).                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `Referrer-Policy`                      | `no-referrer`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | OWASP: `no-referrer`                                                                                                                                                                                                                                                                                                 | **Keep**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `Permissions-Policy`                   | Empty allowlists for `camera`, `display-capture`, `fullscreen`, `geolocation` and `microphone`. The strict set is longer and disables more features.                                                                                                                                                                                                                                                                                                                                                                                                                                                       | OWASP lists a deny-by-default set of features. Our fetch of its JSON was truncated, so the full list is read from `ci/headers_add.json` in the OWASP repository in phase 2.                                                                                                                                          | **Change**: extend the non-strict default to OWASP's full denial list for features we do not use. Our four `self` grants (camera, display-capture, fullscreen, microphone) stay.                                                                                                                                                                                                                                                                                                                                                                                                  |
| `Cross-Origin-Opener-Policy`           | `same-origin`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | OWASP: `same-origin`                                                                                                                                                                                                                                                                                                 | **Keep**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `Cross-Origin-Embedder-Policy`         | `credentialless` in production, `unsafe-none` in development. The `/_nuxt/**` route rule in `apps/web/configuration/routeRules.ts` sets `credentialless` in development too. Strict: `require-corp` in production.                                                                                                                                                                                                                                                                                                                                                                                         | OWASP: `require-corp`. MDN: `require-corp` loads only same-origin resources, or those that set `Cross-Origin-Resource-Policy` to allow embedding; `credentialless` loads no-cors cross-origin resources without a CORP header, sending them without credentials.                                                     | **Keep** `credentialless`. Under `require-corp` a cross-origin no-cors load needs CORP permission, and a CORS-mode load needs a successful CORS check instead. Desmos is a CORS-mode load, since `useScript` gives a cross-origin script `crossorigin="anonymous"`; the grapesjs CDN's scripts and stylesheets and MediaPipe's script are loaded by the libraries themselves. Whether each resource's response meets its request mode is unverified, so `require-corp` waits on that check in phase 2. This is a deliberate deviation from OWASP and the reason is recorded here. |
| `Cross-Origin-Resource-Policy`         | `same-origin`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | OWASP: `same-origin`. The Fetch standard §3.7 allows `same-origin`, `same-site` and `cross-origin`.                                                                                                                                                                                                                  | **Keep**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `X-Content-Type-Options`               | `nosniff`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | OWASP: `nosniff`                                                                                                                                                                                                                                                                                                     | **Keep**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `X-DNS-Prefetch-Control`               | `off`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | OWASP: `off`                                                                                                                                                                                                                                                                                                         | **Keep**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `X-Permitted-Cross-Domain-Policies`    | `none`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | OWASP: `none`                                                                                                                                                                                                                                                                                                        | **Keep**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `Origin-Agent-Cluster`                 | `?1`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | MDN: `?1` asks for an origin-keyed agent cluster, and any other value is ignored.                                                                                                                                                                                                                                    | **Keep**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `X-XSS-Protection`                     | `0`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | MDN: the header is non-standard and deprecated, and it recommends `Content-Security-Policy` instead. ## Our overrides

`apps/web/configuration/security.ts` sets the module's options, and two other files add to it: `apps/web/configuration/routeRules.ts` and `apps/web/server/plugins/security.ts`. Each override and whether it still makes sense:

| Override                                                                               | Where                        | Still right?                                                                                                                                                                                                                                                                                            |
| :------------------------------------------------------------------------------------- | :--------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `img-src` from `ImageSourceWhitelist`                                                  | `security.ts`                | **Keep**.                                                                                                                                                                                                                                                                                               |
| `img-src` widened with `https:` for the messages and resource routes                   | `server/plugins/security.ts` | **Keep**. It widens image sources for the images members embed in messages and resources, which is the accepted risk the [security](/docs/architecture/security) skill records.                                                                                                                         |
| `script-src: "'unsafe-eval'"`                                                          | `security.ts`                | **Change**. The module merges arrays by replacement (`utils/merge.mjs`, its replace-array defu), so this string replaces the whole default `script-src`. The `'self'`, `https:`, `'strict-dynamic'` and nonce sources go with it. The override should list every source the directive needs.            |
| `script-src-elem` with `'unsafe-inline'` and no nonce                                  | `security.ts`                | **Verify**. With `ssg.hashScripts` on, the module appends script hashes to `script-src-elem` (`30-cspSsgHashes`), and CSP3 ignores `'unsafe-inline'` once a hash is present. Whether a built page then blocks its inline Nuxt data script is unverified and is checked against a built page in phase 2. |
| `style-src-elem` with `'unsafe-inline'`, `self` and the grapesjs CDN                   | `security.ts`                | **Keep**.                                                                                                                                                                                                                                                                                               |
| `worker-src` with `self` and `blob:`                                                   | `security.ts`                | **Keep**. It serves pdfjs and Desmos.                                                                                                                                                                                                                                                                   |
| `permissionsPolicy` grants for `camera`, `display-capture`, `fullscreen`, `microphone` | `security.ts`                | **Keep**. LiveKit and the PDF viewer need them.                                                                                                                                                                                                                                                         |
| `rateLimiter: false`                                                                   | `security.ts`                | **Keep**. The rate limiter defects in the [upstream audit](/docs/nuxt-security-module/upstream) do not reach us while it is off.                                                                                                                                                                        |
| `xssValidator: false`                                                                  | `security.ts`                | **Keep**. Its comment and `security.test.ts` record the measurement behind it.                                                                                                                                                                                                                          |
| `requestSizeLimiter` from `MAX_REQUEST_SIZE` and `MAX_FILE_REQUEST_SIZE`               | `security.ts`                | **Keep**. The module defaults are 2 MB and 8 MB, and ours come from shared constants.                                                                                                                                                                                                                   |

## Sources

- [OWASP Secure Headers Project](https://owasp.org/www-project-secure-headers/), whose recommended values are in its repository's [`ci/headers_add.json`](https://raw.githubusercontent.com/OWASP/www-project-secure-headers/master/ci/headers_add.json).
- [CSP Level 3](https://www.w3.org/TR/CSP3/), for `frame-ancestors`, `script-src-elem` and the `'unsafe-inline'` rules.
- [Fetch standard](https://fetch.spec.whatwg.org/), §3.7 for `Cross-Origin-Resource-Policy`.
- [RFC 6797](https://www.rfc-editor.org/rfc/rfc6797), for `Strict-Transport-Security`.
- MDN: [`Cross-Origin-Embedder-Policy`](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Cross-Origin-Embedder-Policy), [`X-XSS-Protection`](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/X-XSS-Protection), [`Origin-Agent-Cluster`](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Origin-Agent-Cluster) and [`X-Frame-Options`](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/X-Frame-Options).
