# Genshin parity

Each screen, scene and piece of music held to its reference, and the tools that measure them.

Greps, over the scope, with explicit paths (zsh does not split a variable into pathspecs):

1. `git grep -n -i "recordings owed"` over `packages/genshin-interface packages/genshin-world scripts/src/services/genshinParity scripts/src/services/genshinAssets scripts/src/models/genshinParity`. A provisional value names the roadmap's list of owed recordings, which the roadmap holds as its `## References sought`; every hit is a stale name for it, and a true one is renamed to that heading.
2. `git grep -n -E 'WIKI_API_URL|WIKI_ORIGIN|api\.php'` over the same paths. Each hit is a read of the wiki's API, which answers HTTP 200 with an `error` key in place of its query, so an answer is parsed by its schema or read through `readWikiJson`'s guard before anything is written to a cache. A hit that writes before it parses is a true one; the wiki readers are `readFamilyLabelRedirects`, `readWikiPage`, `readImaginariumSeasonTitles`, `readWikiTalentPages`, `readWishPageTitles` and `readWholeScreenImages`.
3. `git grep -n -E '(^|[^0-9A-Za-z_.])[1-9][0-9_]{3,}([^0-9A-Za-z_.]|$)'` over `packages/genshin-world/src/services packages/genshin-world/src/models packages/genshin-world/src/composables packages/genshin-world/src/store packages/genshin-interface/src scripts/src/services/genshinAssets`, with `':!**/generated/**' ':!*.test.ts' ':!*.browser.test.ts' ':!*.fixture.ts' ':!*.reference.ts' ':!*.bench.ts' ':!*.vue' ':!*.json'` excluded. Each hit is a game id or a number the game sets. Each one's value is then looked up in the dump's `ExcelBinOutput` (the `EXCEL_DIRECTORY` of `scripts/src/services/genshinText/constants.ts`) with `rg -l -w '<value>' <EXCEL_DIRECTORY>`: a value in a table that holds it with its game id is a hand-typed game table, moved to a stat table or a `GameDataset` member and read by key; a value no table names is the app's own or wiki-only, and stays with its reason.
4. `git grep -n -i 'wiki'` over the same paths, with the same exclusions. A comment that cites the wiki for a value names a scalar or a table the dump may hold, and each is checked as in 3 before it stays.

Read unit by unit, since no grep decides them:

- A `] ?? []` fallback on an index. Most of the ninety hits are a keyed map with no entry for a key, or the type checker's answer to an index, where empty is the right value; the defect is a parallel array the loop assumes is as long as the loop, read past its end and measured as nothing, which only the loop's bounds show.
- A note string that states a fact about what was read, such as "none", for a value the code never reads. A note's claim is checked against the branch that writes it, which no grep names.

The first run of item 3 settled these, by file, since the area list names no unit for some of them:

- `packages/genshin-world/src/services/forging/constants.ts`: "FORGE_QUEUE_PLAYER_LEVELS" was `ForgeUpdateExcelConfigData`'s `playerLevel` (1, 5, 10, 15), and is now the `stats/forgeQueuePlayerLevels` table, read by key and threaded through `startForge`, `computeForgeQueueCount`, `computeForgeQueueSlots` and the Forge screen. `FORGE_ORE_ITEM_IDS` names ten ids all in `MaterialExcelConfigData`, but the enhancement recipes name eight of them, so it is not derivable from the recipes and stays.
- `packages/genshin-world/src/services/adventureRank/constants.ts`: the wish, co-op and handbook unlock quests are "OpenStateConfigData"'s "OPEN_STATE_COND_QUEST" params (2010001, 35001). The screen-to-row mapping is not in the dump, since "SystemOpenUIConfigData" names icons and not screens, so `ScreenKindOpenRankMap` (the wiki's Game System Unlocks table) is not moved.
- `scripts/src/services/genshinAssets/stats/constants.ts`: "ArtifactSlotMainPropDepotMap" (3000, 4000, 5000, 2000, 1000) is the reliquary table's `mainPropDepotId` beside each slot's equip type, and is now derived from that table by `toArtifactSlotMainPropDepotMap`, the depot most of a slot's pieces draw. `TRAVELER_AVATAR_IDS` and the Wwise ids in `scripts/src/services/genshinAssets/shared/constants.ts` are game ids.
- `packages/genshin-world/src/services/weapon/constants.ts`: `EXP_PER_MORA` (ten EXP to one Mora) and `FODDER_EXP_SHARE` (0.8) are the wiki's Weapon EXP page's rates, and no weapon table of the dump holds either. "TrainingGuideExpCostConfigData" prices each EXP item at one Mora a point of its EXP, which is not the enhancement's ten points to a Mora, and the dump's 0.8 in a training-guide table, "TrainingGuideGlobalExcelConfigData", sits in an obfuscated field that cannot be named. Both stay, their comments naming the wiki.
- `packages/genshin-world/src/services/gathering/OreItemIdBreakPoiseMap.ts`: refuted, since no table in the dump has a poise key, so its values are the wiki's Mineral page only.
- `packages/genshin-world/src/services/wish`: refuted, since "GachaRestrictConfigData" is the dump's only gacha table and holds no rates, so the banners' rates are the wiki's.
- `packages/genshin-world/src/models/quest/QuestId.ts`: refuted, since the list is the set of quests the app carries, each row a choice, and each quest's data is read from the dump by `QuestLoaderMap`.
- `scripts/src/services/genshinAssets/trials/wikiTrialBuilds.ts`: the wiki's Character Trial pages by date, cited to each page, not checked against the dump.
- `packages/genshin-world/src/services/artifact/constants.ts`: its wiki weights are not checked against the dump.

The class F run (hand-typed game tables) settled these by file:

- `packages/genshin-world/src/services/inventory/ItemCategoryRoomMap.ts`: the dump's `ConstValueExcelConfigData` names each category's limit ("CONST_VALUE_WEAPON_ITEM_LIMIT" holds 2000, "CONST_VALUE_FURNITURE_ITEM_LIMIT" 2600), but its reliquary row holds 2700 and 2900 where this map has the wiki's artifact room of 2400, and each row holds two values. The room's value waits on which one the bag holds, so the map is not moved.
- `packages/genshin-world/src/services/inventory/constants.ts`: `MAX_ITEM_QUANTITY` is the ceiling `buildItems` checks every published stack limit against, so it stays. `INVENTORY_KIND_LIMIT` (2300) is the wiki's, and no dump row holds it.
- `packages/genshin-world/src/services/imaginarium/constants.ts`: the installed dump holds no Imaginarium table, so the Companion price is not read from it and its comment says so.
- `packages/genshin-world/src/services/kit/characters`: a kit's dump-backed values reach its record only through the labelled Tables candidates of its three combat talents (`scripts/src/services/genshinAssets/kits/tables/getTableKitCandidates.ts`), which read no passive and no constellation row. A kit constant that a row of its own proud skill groups holds stays until that path reads the row. Small integers (0 to 6) match almost any row, so they are not counted as held. Character ids are id-keyed code constants and stay, and the per-1000 max-health divisors are units.
