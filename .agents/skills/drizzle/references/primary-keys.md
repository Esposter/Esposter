# Primary Keys

Read when choosing a new table's primary key.

- **Text id for an entity referenced by other tables** — `id: text().primaryKey()` with a `$defaultFn` that makes the id, as `roomRolesInMessage` writes it (`packages/db-schema/src/schema/message/roomRolesInMessage.ts`).
- **Text PK for natural-key tables** — computed text PK when uniquely identified by a domain-derived string.
- **Composite PK for pure join tables** — `primaryKey({ columns: [col1, col2] })` when no surrogate is needed.
- **Random-id PK** — when a generated random code already uniquely identifies the row (invites, call sessions), use it as `id: text().primaryKey()` directly, generated by `createId(LENGTH)` from `#shared/util/math/random/createId`. Do not add a separate surrogate id alongside a `token`/`code` column. The field is always named `id` for shape consistency, with a colocated `{ENTITY}_ID_LENGTH` constant + length CHECK, as `CALL_ID_LENGTH` and `callSessions_id_length_check` are (`packages/db-schema/src/schema/message/callSessionsInMessage.ts`).
