# The `ai:` Script Catalogue

Read when a sweep, a review or a skill needs the script that runs its scan — every root `ai:<domain>:<verb>`
entry, what it prints, and what it costs. The naming rule is the `skill-authoring` skill's (`references/embedded-recipes.md`);
this page is the list. What each `ai:sweep:*` command costs end to end is `scripts/src/sweeps/commands.bench.md`, never a number restated here — its clock is boot, spawns and reads before it is any unit's (`runtime-efficiency` skill, "A script's clock"), and the unit whose cost outgrows the corpus carries a colocated bench of its own (the `bench` skill, `references/running-benchmarks.md`).

Each is a `pnpm -C scripts <same name>` delegation to `scripts`, whose entrypoint is
`scripts/src/<domain>/<verb>/index.ts` and whose functions sit under `scripts/src/services/<domain>/<verb>/` with a colocated test. One `ai:sweep:*` per scan. `scripts/src/workspace/aiScripts.test.ts` holds the table to the root manifest both ways, so a script added without its row fails there.

| `pnpm ai:citations:sync [<base>]`                                                                       | Rewrites every backticked path citation in the docs, the agent tree and the READMEs for the renames `git diff -M` reports since `<base>` (`HEAD` by default), so a move updates its citations without a hand grep (the `docs` skill, `references/moves-and-renames.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `pnpm ai:review`                                                                                        | Every window of the commits `ai/queue` holds past `main`, planned at once (the longest run of commits under the file cap), every batch reviewed in one pool of haiku reviewers until the run's deadline, `main` fast-forwarded through the passed prefix as it grows, and each passed window's findings opened as `review` issues. `--dry-run` prints the plan and runs nothing. The Review workflow runs it.                                                                                                                                                                                                                                                                                                                                                                               |
| `pnpm ai:review:fix`                                                                                    | One review issue's findings file, fixed by one fixer session on `ai/queue`'s tip: its commits land on the queue, and the issue is closed when every finding is settled or narrowed to the ones still open. The Review workflow runs it once per issue, each in its own job.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `pnpm ai:review:settle`                                                                                 | The open review issues, oldest first, one settler session each on the queue's tip: each finding fixed, refuted or recorded in its area's proposal or roadmap page, its commits landed, and the issue closed. An issue another live run owns is left to that run. The Review workflow's settle job runs it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `pnpm ai:dependencies:score [--sort bundle] [--analyze]`                                                | Scores each catalog entry for how sensibly it could be absorbed, with its client bundle bytes from `nuxt analyze`'s report and its install cost (`apps/web/content/docs/architecture/dependency-admission.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `pnpm ai:fleet:claim <id> [--worker <id>]`                                                              | Takes an entry for this worker as a claim ref on origin: exit 0 when won, exit 1 naming the holder (`machine/worker`) when another worker's live claim keeps it (the `throughput` skill, `references/fleet.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `pnpm ai:fleet:data`                                                                                    | The game data each fleet machine holds, copied over ssh on the local network only (the `throughput` skill, `references/fleet.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `pnpm ai:fleet:hold <id> [--worker <id>]`                                                               | Holds a fleet entry for this worker for as long as it runs (the `throughput` skill, `references/fleet.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `pnpm ai:fleet:next`                                                                                    | The next takeable fleet entry for this machine's lane and kind, claimed for a worker, printed as `claimed <id> as worker <worker>` (the `throughput` skill, `references/fleet.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `pnpm ai:fleet:profile`                                                                                 | Writes what this machine detects into its profile, keeping the id and areas the user set, and prints the profile (the `throughput` skill, `references/fleet.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `pnpm ai:fleet:release <id> [--worker <id>]`                                                            | Deletes an entry's claim held by this worker, or with `--miss` keeps it as the holder's final word (the `throughput` skill, `references/fleet.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `pnpm ai:fleet:status`                                                                                  | Every machine's last sample and what it last pushed, every claim's holder, age and state, and every waiting unit with its blocker, fetched fresh (the `throughput` skill, `references/fleet.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `pnpm ai:gcsim:configs`                                                                                 | Reads every character's `config.yml` at gcsim v2.47.2 and names each the kit reader refuses, so a parse break surfaces before a publish                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `pnpm ai:identifiers:rename <map.json>`                                                                 | Every source it rewrote renaming the map's names where each file binds them, in code only (the `file-organization` skill, `references/large-renames.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `pnpm ai:machine:watch`                                                                                 | Prints one line when the machine goes idle or tight, writes its reading to `~/.esposter/machine/state.json`, and sweeps the orphaned searches it leaves behind; the genshin-mods pulse mod keeps it running (the `throughput` skill, `references/machine-efficiency.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `pnpm ai:package:new <name> [--kind library, nuxt-module or plugin] [--description "..."] [--register]` | Prints each repository path it creates or edits, then the next step. It writes files and runs nothing else; the invariants each file satisfies are held by the suites named in `scripts/src/services/package/new/` (the `file-organization` skill, `references/new-package.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `pnpm ai:proposals:report`                                                                              | One line per open proposal, cheapest first — the files its Key files table names, the cost signals read off their paths and the proposals it waits on — then each area a ship has moved since its last product-review pass (the `building-proposals` skill, `references/choosing.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `pnpm ai:resume`                                                                                        | This machine's leftovers, one row per check with its action: the uncommitted tree, the queue's divergence from origin, linked worktrees, its claims, dead hold pid files, uninstalled plugins and the review's owed and held commits and latest run; exits 1 when any needs one (the `resuming` skill).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `pnpm ai:triage:label <issue> [--dry-run]`                                                              | Reads the issue and applies one of the tracker’s triage roles (`.agents/triage-labels.md`). A reading under the high-stakes bar, and a checkout with no typed-decision tier configured, both leave `needs-triage`; an issue already carrying a triage label is left alone.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `pnpm ai:usage [--days <n>] [--project <name>]`                                                         | Where Claude Code usage went over the last `--days` (default 7) read from the local transcripts, one row per bucket (main, subagent, workflow) and model family with its turns, output, cached reads, cache writes and average context, then the 8 transcripts with the most cached reads and the start of their prompts (the `llm-delegation` skill).                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `pnpm ai:voice-match [names...] [--language en \| ja \| ko \| zh] [--write] [--check]`                  | The reference selection (`apps/web/content/docs/infra/claude-interface/reference-selection.md`): every roster character's story lines — or only the characters named — fetched from the community wiki in one dub, decoded in memory and measured, the line nearest the character's voice chosen, a carrier sentence cloned from it through the plugin's own engine and scored. `--write` regenerates `packages/genshin-persona/src/generated/PersonaReferenceMap.ts`, one map, whole for a roster run and merged for a named one; `--check` measures nothing: it asks the wiki whether each character's effective reference line still exists in all four dubs, exiting non-zero on any missing. Hours over the whole roster, minutes for the check; the models download on the first run. |
| `pnpm ai:skills:extract <spec.json>`                                                                    | Moves `SKILL.md` sections and bullets verbatim onto reference pages from a spec (`ExtractSpec`), leaving each one-line rule in place and indexing every page it creates — the edit a skill pass makes most (the `skill-authoring` skill, `references/skill-pass.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `pnpm ai:unocss:generate "<markup>" [filter]`                                                           | The CSS `apps/web/uno.config.ts` generates for a markup fragment, filtered to the lines naming `filter` — the offline answer to whether a utility resolves and to which property. Delegates to `apps/web`, which holds the config (the `run-app` skill, `references/css-generation.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `pnpm ai:sweep:ledger-coverage`                                                                         | Writes each ledger row's `Swept` date and model in from the `Ledger:`, `Reopens:` and `Co-Authored-By:` commit trailers, syncs a derived ledger's rows to the tree, and prints every trailer naming no row (the `sweeps` skill, `references/ledger-files.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `pnpm ai:sweep:constant-scope`                                                                          | One sweep find recipe, as a tested script rather than a ledger code block (the `sweeps` skill, `references/find-recipes.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `pnpm ai:sweep:file-organization`                                                                       | Every source file with a second export that is not a companion of its first, an exported type outside a models layer with no value twin, or a local type that is not the colocated map — candidates the file-organization pass reads, not findings.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `pnpm ai:sweep:duplicate-prose`                                                                         | Every run of `SHINGLE_SIZE` or more words two docs pages or skills of different owners share, longest first — a candidate for the one-owner rule, since the pass decides which page keeps the prose and which keeps a pointer (the `skill-authoring` skill, `references/one-owner-per-topic.md`). | `pnpm ai:sweep:duplicate-code`                                                                          | Every run of code two files share, longest first, one line per finding with its duplicated line count and the two paths with their start lines, over every code scope with tests, generated output, declarations and import blocks left out — a candidate list for the `quality` ledger, which decides which copy owns the code (`.agents/ledgers/quality/duplicate-code.md`). | `pnpm ai:sweep:skill-docs`                                                                              | Every structural finding over the skill tree, one per `SkillDocsFindingType` — a page over budget, a reference nothing indexes or that cites itself, a citation resolving nowhere, a description or a Settled list out of shape. Every finding but the budget also fails `scripts/src/workspace/skillDocs.test.ts`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
