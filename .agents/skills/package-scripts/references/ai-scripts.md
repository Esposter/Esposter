# The `ai:` Script Catalogue

Read when a sweep, a review or a skill needs the script that runs its scan — every root `ai:<domain>:<verb>`
entry, what it prints, and what it costs. The naming rule is the `skill-authoring` skill's (`references/embedded-recipes.md`);
this page is the list. What each `ai:sweep:*` command costs end to end is `scripts/src/sweeps/commands.bench.md`, never a number restated here — its clock is boot, spawns and reads before it is any unit's (`runtime-efficiency` skill, "A script's clock"), and the unit whose cost outgrows the corpus carries a colocated bench of its own (`bench` skill).

Each is a `pnpm -C scripts run <same name>` delegation to `scripts`, whose entrypoint is
`scripts/src/<domain>/<verb>/index.ts` and whose functions sit under `scripts/src/services/<domain>/<verb>/` with a colocated test. One `ai:sweep:*` per scan.

| Command                                                          | Prints                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pnpm ai:citations:sync [<base>]`                                | Rewrites every backticked path citation in the docs, the agent tree and the READMEs for the renames `git diff -M` reports since `<base>` (`HEAD` by default), so a move updates its citations without a hand grep (`docs` skill, "Mechanical follow-through").                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `pnpm ai:coderabbit:collect [<pr>] [--dry-run]`                  | One review-collector cycle over the release pull request: replies owed for pushed fixes, the gates, a Claude drain of the open findings onto `ai/review-fixes`, the largest window of `ai/queue` under the cap ported and pushed to `develop`, and replies with the pushed sha. `--dry-run` reads and ports into a throwaway worktree and posts and pushes nothing. **Spends a review slot when it pushes.**                                                                                                                                                                                                                                                                                            |
| `pnpm ai:coderabbit:feedback "<pr>"`                             | The newest review's buckets, its unresolved threads with the comment id a reply needs, the stated counts reconciled against them, and the walkthrough's merge risk and pre-merge checks.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `pnpm ai:triage:label <issue> [--dry-run]`                       | Reads the issue and applies one of the tracker’s five triage roles (`.agents/triage-labels.md`). A reading under the high-stakes bar, and a checkout with no typed-decision tier configured, both leave `needs-triage`; an issue already carrying a triage label is left alone.                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `pnpm ai:voice-match [en \| ja \| ko \| zh] [--write] [--check]` | The reference selection (`apps/web/content/docs/infra/claude-interface/reference-selection.md`): every roster character's story lines fetched from the community wiki in one dub, decoded in memory and measured, the line nearest the character's voice chosen, a carrier sentence cloned from it through the plugin's own engine and scored. `--write` regenerates `packages/genshin-persona/src/generated/PersonaReferenceMap.ts`, one map; `--check` measures nothing: it asks the wiki whether each character's effective reference line still exists in all four dubs, exiting non-zero on any missing. Hours over the whole roster, minutes for the check; the models download on the first run. |
| `pnpm ai:sweep:ledger-coverage`                                  | Writes each ledger row's `Swept` date in from the `Ledger:` and `Reopens:` commit trailers, syncs a derived ledger's rows to the tree, and prints every trailer naming no row (`sweeps` skill).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `pnpm ai:sweep:constant-scope`                                   | One sweep find recipe, as a tested script rather than a ledger code block (`sweeps` skill).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `pnpm ai:sweep:duplicate-prose`                                  | Every run of ten or more words two docs pages or skills of different owners share, longest first — a candidate for the one-owner rule, since the pass decides which page keeps the prose and which keeps a pointer (`skill-authoring` skill, "One owner per topic"). A run three pages share is a template and is not reported.                                                                                                                                                                                                                                                                                                                                                                         |
| `pnpm ai:sweep:repeated-list-items`                              | A component writing three or more `v-list-item`s out one by one, with no `v-for` anywhere in it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `pnpm ai:sweep:shared-export-consumers`                          | Every `packages/shared` export naming fewer than two consumer packages, which is what earns a place there.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `pnpm ai:sweep:skill-docs`                                       | The skill tree structural check: a page over budget, a reference nothing indexes, a citation resolving nowhere. Every finding but the budget also fails `scripts/src/workspace/skillDocs.test.ts`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `pnpm ai:sweep:unterminated-results`                             | Every `getResult` call, matched to its closing bracket, whose chain nothing terminates.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
