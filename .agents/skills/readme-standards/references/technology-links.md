# Technology Links

Read when a README names a technology and links its documentation, or when a technology is added to or dropped from a README.

Each technology has one documentation URL: the project's own docs home, or its repository README where it has no docs site. It is written here once. A README links it, never a copy of it, and lists only the technologies it uses. The list is alphabetical; a README's links are alphabetical too.

A package's Related Documentation lists the technology of each of its `dependencies` and `peerDependencies` that appears in the Packages column, plus any tool its own text names as the way to run it, such as Vitest in its Commands. A Packages cell of "none" means the technology is linked only when a README's text names it.
