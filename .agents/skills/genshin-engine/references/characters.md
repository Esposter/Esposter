# Characters

Read when a character's model, its MMD pack, or its materials and outline are in question.

- **A character is its official MMD pack, read at run time by the engine's own PMX reader** (`parsePmx`, into three's space as it reads), never a loader dependency and never a committed file. A pack is read from a copy its reader holds, or from the official packs published under `characterPacks/`: a player's own release, loaded on the character screen, read in the page and kept in the browser's storage, ahead of what the development server serves under `nuxt dev` from the developer's own extracted packs, both through a `CharacterPackReader`, and the rules reading a release's folder (`chooseCharacterPackModel`, `resolveCharacterPackTextures`, `chooseCharacterTermsFile`, `decodeCharacterTerms`) belong to `genshin-world` and import nothing of Node's, one set of rules for the page and the server alike. No pack byte leaves the browser. Its materials are `createCharacterMaterial`, not the environment's toon material: the same ramp and rim with no wetness, blended in the model's order as MMD draws it, outlined only where the model sets an edge (`openspec/specs/genshin/characters/README.md`).
