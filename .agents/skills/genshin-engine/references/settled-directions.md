# Settled directions

Read when a proposal matches a Settled line and its full statement is needed.

Each Settled line in `SKILL.md` is one line; this page holds the argument behind each.

## A rigid-body physics engine

Movement is kinematic, so collision is a query service the controller asks; a solver fights the feel (`openspec/specs/genshin/character-controller/design.md`, "A kinematic capsule on queries, no physics engine").

## An ignorePatterns entry for the engine's TSL

The fluid simulator's file stays the only exclusion (`.agents/skills/oxlint/references/ignore-patterns.md`).

## The word teyvat in any name

The world is implicit in "Genshin".

## Shipping assets taken from the game

The engine's own geometry and materials are generated by our own code, re-derived from the game's exports as closely as they allow (`openspec/specs/genshin/scene-derivation/design.md`); the developer's own exports are drawn under `nuxt dev` alone, through a base URL only the development server hands the world (`openspec/specs/genshin/derived-assets/development-exports/design.md`). The one published exception is the official character packs: the owner has stated that HoYoverse permits redistributing them, so the app publishes each pack to the public game data container (`openspec/specs/genshin/characters/published-packs/design.md`). The earlier direction against hosting them is rejected, and that permission is its basis.

## A second renderer path for WebGL

`WebGPURenderer` falls back to WebGL 2 on its own.
