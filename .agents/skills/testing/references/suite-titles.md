# Suite titles

Read when the subject of a `describe` has no importable function reference — a default export, a constant, a suite over a workspace invariant — or when the export's own casing is not camelCase. The rule (`describe(functionRef, …)`, a string only when no reference exists, naming the export) is in `SKILL.md`; this page is the casing and the edge cases.

The string names the file's export, never the topic the test happens to cover (`describe("drizzleAdapterConfiguration")`, not `describe("better-auth joins")`); a default export is named by its file (`describe("unoConfig")` for `uno.config.ts`, `describe("errorAlert")` for a plugin entrypoint), and a suite with no subject file at all — a workspace invariant under `scripts/src/workspace/` — takes its own camelCase file name (`describe("sideEffects")`), never a library function it happens to call. **The title is camelCase whatever the export's own casing is** — a PascalCase constant is titled with its first letter lowered (`describe("achievementDefinitionMap")` over `AchievementDefinitionMap`), which is what keeps every suite title in the repo one shape rather than splitting on what kind of thing each file happens to export. A SCREAMING_SNAKE_CASE export is **camelCased whole** — `NON_SOURCE_SUFFIXES` is `nonSourceSuffixes`, never fOO_SUFFIXES, which is what lowering only the first letter produces. `vitest/prefer-lowercase-title` rejects the verbatim name outright, so this is enforced rather than preferred. Never pass the constant itself where its value is a string — `describe(SOURCE_CONDITION)` titles the suite with the value, so nobody grepping the name finds it.

## The rule in full

- **`describe(functionRef, …)`** — the function reference itself; a string only when no importable reference exists, and then it **names the file's export**, never the topic the test happens to cover, camelCased whole whatever the export's own casing (`vitest/prefer-lowercase-title` enforces it). What the test proves belongs in the test name; the block names what is under test. Flat — a nested `describe` is a `no-restricted-syntax` error, and what the group said goes into each test's name; `describe.each` over a matrix (the UI library's per-style run) is not a group and stays.
