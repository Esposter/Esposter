# Data sources

Read when a table is missing from the dump, a dump field is obfuscated, or a fit or loop publishes its record. The one-line rules are in `SKILL.md`; this page is their reasoning.

- **A table the dump lacks is fetched from the community repository's `main`, the branch at the install's build, and only after one it holds matches.** `main` is at 7.1.0, the install's build, and `master` is held at the 6.6 patch, which is older. Most of the local dump matches `master` rather than `main` (measured 2026-10-18: 128 of 184 tables at `master`'s sizes, 19 at `main`'s, 37 at both), so for those tables the dump is older than the install and a table taken from it may predate a character or a row. Fetched tables go into `~/Esposter/genshin-parity/text/ExcelBinOutput/`, never the repository. First fetch one table the dump already holds and compare it with `main`'s copy. A table that matches is the install's revision. A table that does not is a different patch, and nothing fetched from it is used until the install decodes it.

- **An obfuscated dump field is modelled under the dump's own key, named in a comment by the game's field, and checked against a value the game shows before its rows are trusted.** The skill depot's passive opens are `LHNAJLJNBAH` at this revision, each phase `KGGNNMEALJM`, checked against the phases the first and fourth ascension passives open at (`openspec/specs/genshin/talents/design.md`). A renamed key reads as absent rather than failing, so a dump at a new revision is checked the same way before the stat run is trusted.

- **A fit or a parity loop publishes its record by key, and the page reads it through the mirror.** `genshin:assets fit <component> --only <part>` and the loops that refit one record (`notes`, `expression`, `instruments`, `calibrate --write`) each replace one key of the hosted game data, and read the record they refine from its last publish, never a file; the parity page's fixtures pass `GAME_DATA_LOCAL_BASE_URL`, which `gameDataMirrorPlugin` answers from the local mirror (the `genshin-data` skill).
