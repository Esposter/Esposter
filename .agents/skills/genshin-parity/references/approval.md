# Approval

Read when approving a screen's images or citing a reference for one. The one-line rules are in `SKILL.md`; this page is their reasoning.

- **No reference, no approval.** A screen's size, colour and place are measured from a reference in its own language and build, never carried over from another client's or guessed; a value with no reference ships only as a best estimate, marked provisional where it stands with what it was estimated from. `ParityReferenceMap.test.ts` fails for any fixture (not `isMotionOnly`) no reference names, so a screen that was never compared cannot reach the suite. A public video that letterboxes the game (a phone, a window) is cropped to the game's screen with the reference's `crop`, and scored over a `region` clear of watermarks; its edges are the video's softness, so a clean score there is an outline of about a percent. A wiki crop of one dialog or button row with no whole frame behind it (the quit prompt's 799 by 475 still) gives its colours and glyphs but no scale: a compare shoots at the reference's own size, so its unit is the crop's and not the game's, and the screen's size is a best estimate held provisional, with a whole frame on the References sought list and a queue item until one is found.

- **Approve with the visual suite once `compare` is clean.** `pnpm -C packages/genshin-world test:visual --run -u`, then commit the image, `Index.<platform>.png` beside the component, with it. A fixture's `variants` are further states, each approved as `Index-<variant>.<platform>.png` (`FIXTURE_VARIANT_SEPARATOR`, a dash, since the repository's `ID_SEPARATOR` is a character Windows rejects in a file name). A screen that moves (a scene) is held still for the suite by its fixture's `stillProps`, read by the suite alone, so the page and the references keep drawing it as it moves. A new image fails its first run, the one that writes it. `genshin-interface`'s components have the same fixtures and images, shot to their own box at 1080 high, and its suite fails for a component without a fixture.
