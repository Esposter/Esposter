# Triage Labels

The skills speak in terms of five canonical triage roles. This tracker's label string **is** the role name in every case, so a skill naming a role (e.g. "apply the AFK-ready triage label") applies that string verbatim:

| Label             | Meaning                                  |
| ----------------- | ---------------------------------------- |
| `needs-triage`    | Maintainer needs to evaluate this issue  |
| `needs-info`      | Waiting on reporter for more information |
| `ready-for-agent` | Fully specified, ready for an AFK agent  |
| `ready-for-human` | Requires human implementation            |
| `wontfix`         | Will not be actioned                     |

A label whose string ever diverges from its role name gets a second column here; until then there is nothing to map.
