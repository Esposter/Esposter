# Rejected

Ideas we decided against. One page per idea with the rationale — check here before proposing an idea; never re-argue a decided one. The recurring theme: the editor serves a casual platform, and anything pushing toward full Excel territory is out.

- [URL import](/docs/file-table-editor/rejected/url-import) — fetch a remote CSV/JSON URL instead of uploading.
- [Multi-sheet XLSX](/docs/file-table-editor/rejected/multi-sheet-xlsx) — import and merge multiple workbook sheets.
- [Markdown export](/docs/file-table-editor/rejected/markdown-export) — expose the internal markdown serializer as an export format.
- [Saved filter presets](/docs/file-table-editor/rejected/saved-filter-presets) — name and persist active filter sets.
- [Fill down](/docs/file-table-editor/rejected/fill-down) — fill empty cells downward from the last non-empty value.
- [Regex find & replace](/docs/file-table-editor/rejected/regex-find-replace) — regular-expression find and replace across cells.
- [Row grouping](/docs/file-table-editor/rejected/row-grouping) — Excel-style outline grouping by column value.
- [Conditional formatting](/docs/file-table-editor/rejected/conditional-formatting) — highlight cells based on value conditions.
- [Cell validation rules](/docs/file-table-editor/rejected/cell-validation-rules) — per-column validation such as "must be positive".
- [Named checkpoints](/docs/file-table-editor/rejected/named-checkpoints) — named snapshots in the history stack.
- [Row description](/docs/file-table-editor/rejected/row-description) — a per-row free-text note.
- [Column freeze / pin](/docs/file-table-editor/rejected/column-freeze-pin) — keep arbitrary columns visible while scrolling.
- [Column-scoped find & replace](/docs/file-table-editor/rejected/column-scoped-find-replace) — restrict find & replace to one column.
