# Password Auth

Adding email/password registration next to Google/GitHub/Facebook.

**Why not:** Passwords drag in verification mail, reset flows, breach-list checking, and credential-stuffing surface — a standing operational burden that three major OAuth providers already cover for a casual platform's entire audience. better-auth makes flipping it on easy; _operating_ it responsibly is the cost, and it buys no reach.
