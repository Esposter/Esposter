# Prestige

An ascension mechanic: voluntarily reset buildings/upgrades/points in exchange for a permanent production multiplier that compounds across runs.

**Why deferred:** Prestige only matters once players exhaust a run. The save-schema question it forces (a prestige currency field) is cheap on the normalized id-based save ([game loop and saves](/docs/clicker/game-loop-and-saves)), and with [all-building upgrades](/docs/clicker/buildings-and-upgrades) shipped the content ceiling is finally reachable — but no one has actually hit it yet.

**Revisit when:** players report exhausting the content (every upgrade bought — the ClickerCompletionist achievement unlocking is the concrete signal).
