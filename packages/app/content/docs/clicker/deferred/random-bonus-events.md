# Random Bonus Events

Timed clickable bonuses that appear at random intervals and grant a short production or click multiplier — the mechanic that makes players keep the tab focused.

**Why deferred:** Real engagement value, but it needs buff state the game doesn't have (temporary effects with expiry interacting with the effect engine) plus art/sound. The active-play loop should first be worth boosting — today the mid-game has nothing to spend bursts on.

**Revisit when:** [milestone achievements](/docs/proposals/clicker/milestone-achievements) and [all-building upgrades](/docs/proposals/clicker/all-building-upgrades) have shipped, making active sessions rewarding.
