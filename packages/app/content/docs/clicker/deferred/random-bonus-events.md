# Random Bonus Events

Timed clickable bonuses that appear at random intervals and grant a short production or click multiplier — the mechanic that makes players keep the tab focused.

**Why deferred:** Real engagement value, but it needs buff state the game doesn't have (temporary effects with expiry interacting with the effect engine) plus art/sound. The content gates ([milestone achievements](/docs/clicker/game-loop-and-saves) and [all-building upgrades](/docs/clicker/buildings-and-upgrades)) have shipped, so active sessions are now worth boosting — the buff-state machinery is what remains.

**Revisit when:** the effect engine grows temporary-effect support for any other reason, or player feedback asks for active-play variety.
