# Number Notation Setting

A display setting switching between the long word notation the game uses today ("1.5 million", via `formatNumberLong`) and a compact `k/M/B` notation.

**Why not:** One game, one number style — a settings surface for a pure formatting preference is UI overhead with no gameplay value, and the long names are part of the game's charm. The short-notation formatter that once sat beside `formatNumberLong` was deleted rather than wired up, so the compact notation has no implementation to switch to and none is planned.
