# Number Notation Setting

A display setting switching between the long word notation and the compact `k/M/B` notation (`formatNumberShort` already exists beside `formatNumberLong`).

**Why not:** One game, one number style — a settings surface for a pure formatting preference is UI overhead with no gameplay value, and the long names are part of the game's charm. `formatNumberShort` is currently dead code; delete it or wire it, but don't build settings around it.
