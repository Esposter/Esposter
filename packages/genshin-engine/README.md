An anime-style open-world engine for the browser on three.js's WebGPU renderer: toon materials that step light from shade to lit across a narrow ramp, a sky-tinted rim on every silhouette, outlines, cascaded shadows, god rays, height fog, bloom, a colour grade and temporal anti-aliasing, procedural terrain and world kits, and a Web Audio synthesizer that plays a score through instruments of harmonics and an envelope, each section swelling and fading by its expression. Every module is plain TypeScript or a TSL node graph with one job, so a scene built with it runs in any framework, and the generators behind it are pure, seeded and tested without a GPU.

It is an unofficial, non-commercial fan engine, not affiliated with HoYoverse. It ships no asset from any game: every mesh, texture, shader and sound is generated by its own code.

## <a name="getting-started">🚀 Getting Started</a>

```bash
pnpm i genshin-engine three
```

```ts
import {
  createFogUniforms,
  createGenshinRenderer,
  createGodraysLight,
  createGradeLutTexture,
  createLightUniforms,
  createPostPipeline,
  createPostUniforms,
  createRampTexture,
  createToonMaterial,
  QualityTier,
  QualityTierSettingsMap,
} from "genshin-engine";
import { Mesh, PerspectiveCamera, Scene, TorusKnotGeometry } from "three";

const renderer = createGenshinRenderer(canvas);
await renderer.init();
const scene = new Scene();
const camera = new PerspectiveCamera();
const rampTexture = createRampTexture({ resolution: 64, softness: 0.08, terminator: 0.52 });
const lightUniforms = createLightUniforms();
scene.add(new Mesh(new TorusKnotGeometry(), createToonMaterial({ color: 0x9ed05a, lightUniforms, rampTexture })));
const godraysLight = createGodraysLight(1024, 50);
scene.add(godraysLight);
const { renderPipeline } = createPostPipeline({
  camera,
  fogUniforms: createFogUniforms(),
  godraysLight,
  gradeLutTexture: createGradeLutTexture({
    contrast: 1,
    highlightTint: [0, 0, 0],
    saturation: 1,
    shadowTint: [0, 0, 0],
    size: 16,
  }),
  postUniforms: createPostUniforms(),
  qualityTierSettings: QualityTierSettingsMap[QualityTier.High],
  renderer,
  scene,
});
renderer.setAnimationLoop(() => renderPipeline.render());
```
