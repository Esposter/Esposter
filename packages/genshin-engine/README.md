# genshin-engine

[![Apache-2.0 licensed][badge-license]][url-license]
[![NPM version][badge-npm-version]][url-npm]
[![NPM downloads][badge-npm-downloads]][url-npm]
[![NPM Unpacked Size (with version)][badge-npm-unpacked-size]][url-npm]

An anime-style open-world engine for the browser on three.js's WebGPU renderer. It includes:

- toon materials that step light from shade to lit across a narrow ramp, with a sky-tinted rim on every silhouette
- outlines, cascaded shadows, god rays, height fog, bloom, a colour grade and temporal anti-aliasing
- procedural terrain and world kits
- a Web Audio synthesizer that plays a score through instruments of harmonics and an envelope, where each section swells and fades by its expression
- recordings that a host decodes, layered over its voices

Each module is plain TypeScript or a TSL node graph with one job, so a scene built with it runs in any framework. The generators behind it are pure, seeded and tested without a GPU.

It is an unofficial, non-commercial fan engine. It is not affiliated with HoYoverse. It ships no asset from any game. Every mesh, texture, shader and sound is generated by its own code.

Design notes live in [the specs](https://github.com/Esposter/Esposter/tree/main/openspec/specs/genshin).

## <a name="getting-started">🚀 Getting Started</a>

```bash
pnpm i genshin-engine three
```

```ts
import {
  createFogUniforms,
  createGenshinRenderer,
  createGodraysLight,
  createGradeLutTexture,
  createLightUniforms,
  createPostPipeline,
  createPostUniforms,
  createRampTexture,
  createToonMaterial,
  QualityTier,
  QualityTierSettingsMap,
} from "genshin-engine";
import { Mesh, PerspectiveCamera, Scene, TorusKnotGeometry } from "three";

const renderer = createGenshinRenderer(canvas);
await renderer.init();
const scene = new Scene();
const camera = new PerspectiveCamera();
const rampTexture = createRampTexture({ resolution: 64, shade: 0, softness: 0.08, terminator: 0.52 });
const lightUniforms = createLightUniforms();
scene.add(new Mesh(new TorusKnotGeometry(), createToonMaterial({ color: 0x9ed05a, lightUniforms, rampTexture })));
const godraysLight = createGodraysLight(1024, 50);
scene.add(godraysLight);
const { renderPipeline } = createPostPipeline({
  camera,
  fogUniforms: createFogUniforms(),
  godraysLight,
  gradeLutTexture: createGradeLutTexture({
    contrast: 1,
    highlightTint: [0, 0, 0],
    saturation: 1,
    shadowTint: [0, 0, 0],
    size: 16,
  }),
  postUniforms: createPostUniforms(),
  qualityTierSettings: QualityTierSettingsMap[QualityTier.High],
  renderer,
  scene,
});
renderer.setAnimationLoop(() => renderPipeline.render());
```

A web worker that generates the ground imports its generators from the `genshin-engine/terrainWorker` subpath, not from the main entry. The subpath holds `computeTerrainTile` and the height, paint and scatter functions that the worker runs. They use three's math and do not use the renderer, so the worker starts without loading the renderer.

## <a name="key-exports">🧩 Key Exports</a>

| Export                   | Kind     | Purpose                                                                                                    |
| ------------------------ | -------- | ---------------------------------------------------------------------------------------------------------- |
| `computeTerrainTile`     | function | Samples one terrain tile's grid, normals and colours from the region's heights                             |
| `createFogUniforms`      | function | One set of fog uniforms for each world, read by the fog pass                                               |
| `createGenshinRenderer`  | function | A three.js WebGPU renderer, falling back to WebGL 2 when WebGPU is missing                                 |
| `createGodraysLight`     | function | A second, unlit sun, with one shadow map that covers the view the god rays march through                   |
| `createGradeLutTexture`  | function | The colour grade cube, as a 3D texture that the LUT pass samples                                           |
| `createLightUniforms`    | function | One set of light uniforms for each world, shared by every material                                         |
| `createPostPipeline`     | function | Builds the frame's post chain over a scene, from outlines to grade and anti-aliasing                       |
| `createPostUniforms`     | function | The post chain's uniforms: outline colour and thickness, god-ray colour, grade and white balance           |
| `createRampTexture`      | function | A one-row texture of the irradiance that the toon lighting steps between                                   |
| `createToonMaterial`     | function | The environment's toon material, stepping from shade to lit on the world's ramp, and drawing the sky's rim |
| `QualityTier`            | enum     | The three quality tiers that set a renderer's cost                                                         |
| `QualityTierSettingsMap` | const    | What each quality tier spends: shadow maps, cascades, god-ray steps, bloom and anti-aliasing               |
