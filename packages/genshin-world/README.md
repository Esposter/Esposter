# @esposter/genshin-world

Genshin Impact's world, rebuilt as an unofficial, non-commercial fan work on [`genshin-engine`](../genshin-engine). It holds everything that is the game's rather than any engine's:

- the catalogue of regions, areas and subareas;
- each region's authored data: its heights, colours, look and landmarks;
- the TresJS components and composables that build all of it.

It ships no asset from the game: every mesh, texture and shader is generated by code.

The package is private: the app is its one consumer. The app mounts `GenshinWorld` inside its own `TresCanvas` and passes in only what its bundler and server decide:

```vue
<script setup lang="ts">
import { GenshinWorld } from "@esposter/genshin-world";
import TerrainTileWorker from "@esposter/genshin-world/terrainTileWorker?worker";
</script>

<template>
  <GenshinWorld
    :create-terrain-worker="() => new TerrainTileWorker()"
    :is-tuning="isDevelopment"
    :quality-tier
    region-data-base-url="genshin"
  />
</template>
```

Region data lives in `src/data/regions/<region>.json`, and the app's server serves it at the base URL, so a region is fetched as the camera comes within reach and released as it leaves. The design is in the app's docs under `/docs/genshin`.
