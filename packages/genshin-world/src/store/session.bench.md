Auto-generated by the BenchmarkMarkdownReporter on `pnpm bench`, colocated beside the bench file (a

`vs base` is a throughput multiplier against each group's baseline (the `native` task, else the
fastest): `1.00×` is the baseline, higher is faster, lower is slower — a fast task drifting back
toward `1.00×` is a regression. `±rme` is the relative margin of error.
Numbers are machine- and commit-dependent (see Environment); only compare runs from the same host.
