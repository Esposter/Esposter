# Feature Specs — Deprecated

All feature/architecture documentation now lives in `packages/app/content/docs/` and is rendered at `/docs` by @nuxt/content. The old `features/` and root `architecture/` trees are legacy sources pending deletion — **do not add or update files there**.

Use the **`docs` skill** for all documentation conventions: layout, frontmatter, the one status rule, single-responsibility files, proposals, `deferred/`/`rejected/` registries, roadmaps, and the sequential per-area lifecycle.
